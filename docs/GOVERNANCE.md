# Association profiles — 2026-10-06

Content editors/administrators manage Committees & people: executive, sub-committee
and founding profiles with name, association role, committee, profession, biography,
term label, display order and an optional portrait. Records are editorial association
profiles, not authentication users, approved members or grants of staff access.

Draft edits preserve the current published snapshot. Explicit confirmation is
required before publishing the saved version. Withdraw removes it from the public
site and retains revisions. Server-side version checks prevent stale publication.
Actions are audited, and every saved/published/withdrawn version retains its body.
Term text does not automatically assign or end a person's association role.

Portrait choices are restricted to explicitly published editorial media. Private
application documents and unknown IDs are rejected. Generated foreign keys preserve
media references in drafts, publications and history. If a portrait is withdrawn
from the media library, public profile rendering stops using it. Profiles appear
under the corresponding About/Governance submenu section, preserving sitemap order.
Real rosters and publication permissions must be confirmed by TPA before publishing.
